```bash

cd usme
```

All configuration is managed through the central `usme_config.grok` file, which is written in a custom Lisp-like domain-specific language (DSL).

3.  **Start the Engine:**
    ```bash
    ./bin/usme-kernel --mode=HYPER-AWARE --debug-level=PHILOSOPHICAL &
    ```
